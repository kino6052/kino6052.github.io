面向中型企业的 Alphabank

银行仪表板应用程序

Alphabank 不仅是我工作的第一家金融科技公司，也是我在俄罗斯工作的第一家科技公司。

他们的主要堆栈是 React+Redux 微前端。 我在那里工作的经历非常棒，因为这些团队非常有才华、敏捷且多才多艺。

使用的管道非常标准。 该架构大致分为前端、中间和后端部分。

我认为 Alphabank 的 UI 设计是我在整个职业生涯中见过的最好的银行应用程序 UI 设计之一。

我非常感谢有机会成为这家伟大公司的承包商。
